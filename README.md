# Odoo To-Do Management  An Odoo 17 addon for creating and tracking tasks.  ## Features 
- Create and assign tasks with due dates, descriptions, estimated time, and subtasks.
- Track task progress through New, In Progress, Completed, and Closed states.
- Mark overdue tasks through a scheduled daily check.
- Provide list and form views, task actions, and a QWeb report.

## Built with

- Odoo 17
- Python
- Odoo ORM
- XML views and QWeb reports

## Installation

1. Copy this addon folder into an Odoo `custom_addons` directory.
2. Add that directory to the Odoo `addons_path` configuration.
3. Restart Odoo, update the Apps list, and install the addon.

## Notes

This repository contains the addon only; it does not include the Odoo server source or a database.
